## Opis
Praca ta dotyczy analizy wpływu różnych metod imputacji na klasyfikatory trenowane na danych medycznych. Repozytorium zawiera kod potrzebny do wykonania analizy, oryginalne zbiory danych oraz książkę w postaci pliku pdf, która jest zwieńczeniem całej pracy.

## Technologia
Analiza została wykonana przy pomocy języka Python z wykorzystaniem poniższych bibliotek:
- NumPy
- Pandas
- SciPy
- Scikit Learn
- Matplotlib
- Seaborn
